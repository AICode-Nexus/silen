# Repository Guidance

## Project map

- Read [`docs/project-map.md`](docs/project-map.md) before proposing or
  starting roadmap work.
- Explicit user instructions override the map.
- With no special scope, safely continue the single `Active` item. If none is
  active, select the first `Ready` item whose dependencies are satisfied.
- `Candidate` and `Watch` items are not default-executable.
- Follow the repository's design and implementation-plan workflow before
  changing product behavior.
- When durable mapped work is completed, update the map state and verification
  evidence in the same change set.
- The map grants prioritization, not authority. Do not infer permission to
  publish, deploy, delete data, or change external systems.
